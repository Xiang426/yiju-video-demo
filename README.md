# 一句话改片｜小影概念原型

帮助剪辑新手用日常语言修改AI初稿，通过改动预览与撤销，把结果调整到满意。

## 部署

静态站点，无需构建。GitHub仓库 Settings → Pages → Deploy from a branch → main → / (root)。

启用后预计访问地址：https://Xiang426.github.io/yiju-video-demo/

## 使用

点击“使用出游示例”，生成初稿，尝试保留合照、缩短开头及调整字幕口吻。支持改动确认、前后对比、撤销、失败重试和下载。

## 原型范围

独立产品概念提案，非小影官方产品。AI响应为模拟。6张原创插画与4个预制MP4真实体现30/26秒和字幕变化。无后台、无模型调用、无登录要求；不上传用户文件。

GitHub Pages的中国大陆访问情况取决于具体网络，须另行实测。
